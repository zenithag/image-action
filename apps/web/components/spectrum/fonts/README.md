# Spectrum fonts

Unmodified Adobe variable fonts, bundled so production builds do not depend on Google Fonts responses. Both families retain the existing CSS variables and `font-display: swap`. Only upright faces are used, matching the previous configuration.

- Source Sans 3: `WOFF2/VF/SourceSans3VF-Upright.ttf.woff2`, [upstream revision 87b37a2](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e). SHA-256: `5f16566f7a40d39b339ad26be151fa5a1ab1f0c2574c7a2e619765584a1acbd8`.
- Source Code Pro: `WOFF2/VF/SourceCodeVF-Upright.ttf.woff2`, [upstream revision 803b7e2](https://github.com/adobe-fonts/source-code-pro/tree/803b7e23ec97ae58b6232ea76519a76d428ba268). SHA-256: `d95dc751b4d82141259f5c00c9838addaadd3b4eac30dd7db4a0da4921d77792`.

Both contain the variable weight range 200–900. The upstream SIL Open Font License notices are included in `source-sans-LICENSE.md` and `source-code-pro-LICENSE.md`.
