# Local fonts

These fonts are bundled so production builds do not require access to Google Fonts.
The root layout loads them with `next/font/local` and preserves the existing CSS variables.

- Poppins: regular (400), medium (500), semibold (600), and bold (700).
- DM Sans: variable font, including the existing 400, 500, and 700 weights.

Source: the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl),
directories `poppins` and `dmsans`. Downloaded on 2026-09-30.
Both families use the SIL Open Font License; their license texts are included alongside the font files.
